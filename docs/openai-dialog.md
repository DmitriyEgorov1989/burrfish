# Ограниченный клиент OpenAI

`IAiDialogClient` из `Burrfish.Application.OpenAI` анализирует одно сообщение и ограниченную историю диалога. Реализация `OpenAiDialogClient` отправляет один запрос в `POST /v1/responses` и не выполняет повторные попытки.

## Решения

Клиент принимает только четыре вида решения:

- `Price` и `Services` выбирают утверждённый шаблон приложения; `Text` для них всегда равен `null`.
- `AskClarifyingQuestion` содержит непустой уточняющий вопрос.
- `ProposeHandoff` содержит непустую формулировку потребности для последующего подтверждения клиентом.

Ответ OpenAI запрашивается через строгую JSON Schema и повторно проверяется приложением. Неизвестные действия, дополнительные или повторённые свойства, пустой текст и текст длиннее 1 000 кодовых единиц UTF-16 возвращают `InvalidDecision`.

## Ограничения

- Текущий текст: от 1 до 4 000 кодовых единиц UTF-16 после проверки на пустое значение.
- История: не более 6 сообщений.
- Сообщение истории: от 1 до 1 000 кодовых единиц UTF-16 после проверки на пустое значение.
- Ответ HTTP: не более 65 536 байт.
- Выход модели: не более 512 токенов.
- Таймаут: `OpenAI:TimeoutSeconds`, допустимый диапазон от 1 до 60 секунд, значение по умолчанию 15 секунд.

Текст и история сериализуются как недоверенные пользовательские данные отдельно от фиксированных системных инструкций. Server-side conversation и tools не используются, `store` установлен в `false`.

## Ошибки

Ожидаемые ошибки возвращаются как `AiDialogResult.Error`. Для ответа API сохраняются исходные `Code`, `Message` и `HttpStatusCode`; вызывающий код не должен отправлять их пользователю или записывать полное сообщение в журнал. Rate limit, HTTP `408` и HTTP `5xx` помечаются как временные, а ошибки квоты и лимита расходов не помечаются временными.

Таймаут возвращает ошибку `Timeout`. Отмена вызывающего кода распространяется как `OperationCanceledException`, чтобы верхний уровень мог корректно остановить обработку.

HTTP-журналирование не содержит значений заголовков, тела запроса или ответа. Не следует добавлять журналирование API key, текста диалога, полного model output или исходного сообщения ошибки.
